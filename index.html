📦 Noon 批量上传模板 NIS 双语结构 · 一键导出 CSV

按 Noon Seller Lab 的 NIS（New Item Setup） 模板整理，含英/阿双语列与父子 SKU 变体示例。下载后删除示例行、按实际商品填写，保存为 CSV/TSV/XLS 上传即可。

📋 模板字段与填写要点（点击展开）
字段必填要点
Partner SKU (Unique)🔴全局唯一，无空格/特殊符
Brand🔴系统有则选，否则提新品牌申请
Product Title (EN/AR)🔴双语；英文≤150字符
GTIN🔴EAN/UPC（GS1 购买）
Image URLs🔴公网链接，以 .jpeg 结尾，多图逗号分隔
Long Description / Feature Bullet🟢提升曝光，建议双语
Item Condition🟢仅 New（只能卖全新密封品）
Family / Product Type / Subtype—类目树三级，决定专属属性列
Parent SKU / Parent Group Key / Child / Size Variation—变体父子关系；Noon 目前仅支持「尺码」轴

上传路径：Seller Lab → Catalog → Imports → Import type 选 NIS、Subtype 选 NIS Create/Update → 上传 CSV。多类目或需类目专属属性（如电子型号、食品净含量），请以后台下载的该类目模板补齐专属列。

🔗 粘贴商品链接生成 Noon 模板 丢链接 → 自动解析 → 导出 CSV

把 Noon / Amazon.ae / SHEIN / Namshi / Trendyol 等中东平台的商品页链接粘进来即可识别：支持带/不带 http://、每行一条、一行多条、从聊天软件复制的 <链接> 都行。识别后会立刻生成填写表单，并后台尝试自动抓取标题/图片/价格；即便你网络下公共代理不通抓不到，也能直接手填后一键导出 CSV。
